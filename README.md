🚨 Настоящий SOS
Расширение для TurboWarp Desktop, которое превращает одну кнопку в маленький конец света.

Что это
Настоящий SOS — это расширение, добавляющее блок, который при нажатии:

🚨 Проигрывает настоящий звук сирены по прямой ссылке на mp3/wav

🔊 Синтезирует сирену через Web Audio API, если ссылка не указана

🪟 Открывает 47 вкладок с вечным вопросом «how to center a div»

😌 Ничего не объясняет

Расширение создано в жанре «абсолютно бесполезно, но работает». Это его главная фича.

Зачем
Потому что:

Ты хотел настоящий звук сирены.

Ты хотел кнопку SOS.

Ты не хотел, чтобы это было полезно.

Блоки
Блок	Что делает
SOS с URL [URL]	Играет настоящий звук сирены по прямой ссылке на mp3/wav
SOS (синтез)	Играет синтезированную сирену, если URL нет
открыть 47 вкладок	Открывает 47 вкладок с how to center a div
Как использовать
Открой TurboWarp Desktop.

Add Extension → Custom Extension → Text.

Вставь код расширения.

В блок SOS с URL вставь прямую ссылку на mp3 сирены (не страницу сайта, а сам файл).

Нажми.

Если URL пустой — сработает синтез. Если URL указан — играет настоящий звук.

Где взять настоящие сирены
Directory.Audio — воздушная тревога, полиция, скорая.

BigSoundBank — бесплатные сирены без регистрации.

Catbox.moe / file.io — залить файл и получить прямую ссылку.

Ищи прямой URL на .mp3 или .wav, а не страницу с плеером.

Как это работает
Расширение использует Web Audio API для синтеза и HTML5 Audio для воспроизведения настоящего звука. В десктопной версии TurboWarp это работает без CORS-ограничений браузера.
